# Music Platform — веб-платформа для обмена музыкой

Веб-приложение на Java (Servlets + JDBC + FreeMarker), где пользователи могут загружать треки, создавать подборки («ситуации»), а администратор модерирует контент.

## Основной функционал

### Для всех пользователей
- Регистрация / логин (с валидацией email и логина через AJAX)
- Просмотр главной страницы с поиском по трекам
- Просмотр ситуаций (плейлистов) и треков других пользователей

### Для авторизованных пользователей (USER)
- Загрузка треков (название, аудиофайл) → требуют одобрения админа
- Создание ситуаций (название, описание)
- Добавление треков в свои ситуации (только одобренные треки или предложение трека в ситуацию с последующим одобрением)
- Управление своими ситуациями и треками (редактирование, удаление)
- Личный кабинет (просмотр профиля, удаление аккаунта)

### Для администратора (ADMIN)
- Панель управления: список всех пользователей, треков, ситуаций
- Одобрение / отклонение треков и ситуаций
- Удаление любого контента или пользователей (каскадное удаление)
- Просмотр статистики (можно расширить)

### Дополнительные возможности
- Поиск треков по названию или автору (JSON-ответ через AJAX)
- Фильтры: аутентификация, права доступа, кодировка, логирование действий
- Хранение аватарок и аудиофайлов в облаке (Cloudinary)

## Технологии

- **Java 8+** (Servlets API, JDBC)
- **Apache FreeMarker** (шаблонизатор)
- **PostgreSQL** (база данных)
- **Cloudinary** (хранение файлов)
- **Maven** (сборка, управление зависимостями — предполагается)
- **Логирование:** SLF4J + Logback (или просто `servletContext.log`)
- **Фронтенд:** HTML, CSS (без фреймворков, но есть стили), AJAX (XMLHttpRequest)

## Запуск проекта

### Требования
- JDK 11+
- Apache Tomcat 9+
- PostgreSQL (создать БД `music_db`, пользователя, пароль)
- Аккаунт Cloudinary (бесплатный) — для загрузки файлов

### Шаги

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/Umarrina/music-platform.git
   ```

2. **Настроить базу данных**
   - Выполнить SQL-скрипт из `db/schema.sql` (создать таблицы: `users`, `track`, `situation`, `tracks_situations`).  
     *Скрипта в репозитории пока нет — я постараюсь добавить его позже. Но можно создать на основе сущностей и DAO.*
   - Указать параметры подключения в `config.properties` или через переменные окружения:
     ```properties
     db.url=jdbc:postgresql://localhost:5432/music_db
     db.username=postgres
     db.password=123
     cloudinary.cloud_name=ваш_cloud_name
     cloudinary.api_key=ключ
     cloudinary.api_secret=секрет
     ```

3. **Собрать проект (Maven)**
   ```bash
   mvn clean package
   ```
   Скопировать `target/music-platform.war` в `webapps` Tomcat.

4. **Запустить Tomcat**
   - Зайти на `http://localhost:8080/music-platform/`

### Альтернативный запуск (IntelliJ IDEA)
- Открыть проект как Maven, настроить Tomcat (артефакт `war exploded`), запустить.

## Примеры использования

- **Пользователь** регистрируется, загружает трек, ждёт одобрения админа.
- **Админ** входит в панель, одобряет трек → трек становится доступен на главной странице и в поиске.
- **Пользователь** создаёт ситуацию «Спокойная музыка», добавляет туда одобренные треки (тоже может предложить, но с модерацией).
